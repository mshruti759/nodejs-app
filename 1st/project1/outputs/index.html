AWS learning

Cloud services notebook

EC2

What: Virtual servers in AWS.

Use: Host websites, apps, and cloud labs.

Example: Launch Amazon Linux, install NGINX, deploy static files.

ssh -i key.pem ec2-user@PUBLIC_IP

IAM

What: Identity and access management.

Use: Control users, groups, roles, and permissions.

Example: Create least-privilege S3 access for a user.

aws iam list-users

S3

What: Object storage for files.

Use: Store images, backups, logs, and static assets.

Example: Upload website screenshots and notes.

aws s3 cp notes.pdf s3://my-bucket/

VPC

What: Private cloud network.

Use: Organize subnets, routing, firewalls, and IP ranges.

Example: Place EC2 in a public subnet with a security group.

10.0.0.0/16

Route 53

What: DNS and domain routing service.

Use: Connect a domain name to an EC2 public IP.

Example: Create an A record for your portfolio domain.

example.com → EC2_PUBLIC_IP

CloudWatch

What: Monitoring, logs, metrics, and alarms.

Use: Track CPU, status checks, and application logs.

Example: Create an alarm for high EC2 CPU usage.

aws cloudwatch list-metrics

FAQ

Common beginner questions

Can I host this on EC2?

Yes. Upload the files to `/usr/share/nginx/html` or `/var/www/html` depending on your NGINX configuration.

Do I need a domain?

No for testing. Use the EC2 public IP first, then add a domain when the site is ready.
